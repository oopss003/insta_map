2. 오류 신고

앱이 정상적으로 작동하지 않는 경우 아래 정보를 함께 보내주시면 문제 확인에 도움이 됩니다.

  • 사용 중인 iPhone 모델
  • iOS 버전
  • MAUI 앱 버전
  • 문제가 발생한 기능
  • 문제가 발생하기 전 수행한 동작
  • 가능한 경우 오류 화면의 스크린샷

3. 카메라가 작동하지 않는 경우

MAUI의 카메라 기능이 작동하지 않는다면 iPhone에서 카메라 권한이 허용되어 있는지 확인해 주세요.

설정 → 개인정보 보호 및 보안 → 카메라 → MAUI 허용

4. 마이크 또는 음성 인식이 작동하지 않는 경우

음성 명령 기능을 사용하려면 마이크 및 음성 인식 권한이 필요할 수 있습니다.

설정 → 개인정보 보호 및 보안 → 마이크 → MAUI 허용

설정 → 개인정보 보호 및 보안 → 음성 인식 → MAUI 허용

5. 캘린더 기능이 작동하지 않는 경우

일정 또는 알림을 캘린더에 추가하는 기능을 사용하는 경우 캘린더 접근 권한이 필요합니다.

설정 → 개인정보 보호 및 보안 → 캘린더 → MAUI 허용

6. 로봇 또는 Bluetooth 연결 문제

MAUI와 호환되는 로봇 또는 주변 장치가 연결되지 않는 경우 다음 사항을 확인해 주세요.

  • iPhone의 Bluetooth가 켜져 있는지 확인
  • MAUI의 Bluetooth 권한 확인
  • 로봇 또는 주변 장치의 전원이 켜져 있는지 확인
  • 로봇이 다른 스마트폰에 연결되어 있지 않은지 확인
  • 앱을 종료한 후 다시 실행
  • 필요한 경우 로봇 전원을 껐다가 다시 켜기

7. 앱이 실행되지 않는 경우

앱이 종료되거나 화면이 정상적으로 표시되지 않는 경우 다음 방법을 순서대로 확인해 주세요.

  • MAUI 앱 완전히 종료 후 다시 실행
  • iPhone 재시작
  • App Store에서 MAUI 최신 버전 확인
  • iOS 최신 업데이트 확인

현재 MAUI는 회원가입 및 로그인 기능을 제공하지 않습니다. 따라서 MAUI 서버에서 관리되는 별도의 회원 계정은 없습니다.
