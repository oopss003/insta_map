# Installation footage

User-supplied installation recordings, edited for the public INWAVE renewal homepage.

- `installation-tour.mp4`: 9 seconds, 720 × 1280, 24 fps, H.264, no audio, fast-start metadata.
  - 0–2 s: `KakaoTalk_20261022_145937917.mp4`, source 0–2 s, arcade approach.
  - 2–5 s: same recording, source 32–35 s, shared walkway.
  - 5–9 s: `KakaoTalk_20261022_145930368.mp4`, source 0.5–4.5 s, installed screen.
- `approach.jpg`, `corridor.jpg`, `monitor.jpg`: stills from the same recordings.

The repeated upload of the `145930368` recording is byte-identical and is not represented as an additional installation. Scenes show the actual installation setting; the footage does not establish unique viewer counts, repeated views by individuals, or advertising outcomes.

The homepage loads this clip independently. Character media is loaded only by `/inwave-renewal/experience/`.
